# Home with Lana · Studio

A preview of a private business portal for Town Square Designs / Home with Lana, Lumberton, Texas.

Every home, every dollar, in one quiet place. Open it on a phone, add it to the home screen, and it behaves like an app.

**Live:** https://homewithlana.github.io

## What it is

- **Today**: the three numbers that matter, what needs her this morning, this week's dates, homes in motion.
- **Our Homes**: every project with an illustrated card. Open one for payments, purchases, mood board, photos, dates, and what it earns the studio.
- **The Money**: in, out and what is left; month by month; where it comes from; what each home earns; cash on hand; owed, bills, bank.
- **The Showroom**: what sold, the rhythm of the week, best sellers, running low, what people asked for, what is on the floor.
- **Peace of Mind**: every dollar matched to a job or a bill, anything unusual held for her yes, house rules, who can see and do what.
- **Connected**: the tools it works with (QuickBooks, Houzz Pro, CompanyCam, Square, Stripe, Gusto) and how it runs itself.
- **Client view**: the private page each client would see.

Every number and name is sample data. Dates are computed from today so the preview always reads current.

## Files

Plain HTML, CSS and JavaScript. No build step, no framework, no tracking.

- `index.html` page shell
- `styles.css` design system
- `data.js` sample data
- `visuals.js` illustrated room scenes, textured swatches, charts (all SVG)
- `app.js` behavior
- `manifest.webmanifest`, `sw.js`, icons: install as an app, works offline after first visit
